# KML to Shapefile

A one-page web tool that converts Google Earth files (`.kml` / `.kmz`, up to 1 MB) into ESRI shapefiles (`.shp`).

- Everything runs in the browser. Files are never uploaded or stored.
- Points, lines and polygons each become their own `.shp`.
- Optional: include `.shx`, `.dbf` (attributes) and `.prj` (WGS 84), or keep altitude as 3D shapes.

To use it, open the GitHub Pages link for this repository.
